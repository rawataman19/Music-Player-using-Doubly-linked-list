🎵 Music Player Using Doubly Linked List
This project implements a simple Music Player using Doubly Linked List in C++. It demonstrates how to manage and manipulate a playlist of songs using the properties of a doubly linked list, allowing users to traverse the playlist forward and backward seamlessly.

🚀 Features
Add Songs: Add new songs to the playlist.
Delete Songs: Remove a specific song from the playlist.
Play Next Song: Move to the next song in the playlist.
Play Previous Song: Move to the previous song in the playlist.
Display Playlist: View all songs currently in the playlist.
Circular Playlist: The playlist loops when reaching the end.
🛠️ Technologies Used
Programming Language: C++
Data Structure: Doubly Linked List
📂 Project Structure
main.cpp: Contains the main logic for the music player.
doubly_linked_list.cpp: Implementation of the doubly linked list and its operations.
doubly_linked_list.h: Header file for the doubly linked list.
📖 How It Works
The playlist is managed using a doubly linked list where:

Each node represents a song.
Each node stores:
The name of the song.
Pointers to the next and previous nodes.
User inputs are used to perform operations like:

Adding songs.
Deleting songs.
Playing the next or previous song.
The program ensures smooth navigation through the playlist with the doubly linked list's properties.
